# LyfeStyler - Расширенное MVP

## Реализованный функционал

### 1. Сущности и сценарии

#### 1.1. Фильтрация и поиск
- **Сущность**: ScheduleEvent (события расписания)
- **Параметры фильтрации**:
  - `search` - поиск по названию и описанию
  - `completed` - фильтр по статусу выполнения (true/false)
  - `color` - фильтр по цвету события
  - `date_from` / `date_to` - диапазон дат

#### 1.2. Сортировка и постраничный вывод
- **Сортировка** по полям:
  - `created_at` - дата создания
  - `date` - дата события
  - `title` - название
  - `completed` - статус выполнения
- **Порядок**: asc/desc
- **Пагинация**: page, page_size (до 100 элементов на странице)

#### 1.3. Привязка пользовательских файлов
- **Сущность**: EventFile
- **Привязка к**: ScheduleEvent
- **Хранение метаданных**: имя файла, размер, MIME-тип, ключ в хранилище

---

### 2. Интерфейс фильтрации (React + TypeScript)

#### Компонент: `src/components/EventsList.tsx`

**Форма фильтров (3+ параметра)**:
1. Поле поиска по названию
2. Выпадающий список статуса (все/выполнено/не выполнено)
3. Выпадающий список цвета
4. Дата от / Дата до

**Поиск по ключевым полям**:
- Поиск по title и description через ILIKE

**Сортировка и пагинация**:
- Выбор поля сортировки
- Переключение порядка (asc/desc)
- Выбор количества элементов на странице (5/10/20/50)
- Навигация по страницам

**Сохранение состояния**:
- Состояние хранится в React state компонента
- При изменении фильтров применяется сброс на страницу 1

### 3. Серверная поддержка фильтрации (FastAPI)

#### Endpoint: `GET /events`

**Query-параметры**:
```python
page: int = 1          # Номер страницы
page_size: int = 10    # Размер страницы (1-100)
search: str = None     # Поиск по названию/описанию
completed: bool = None # Статус выполнения
color: str = None      # Цвет события
date_from: str = None  # Дата от (YYYY-MM-DD)
date_to: str = None    # Дата до (YYYY-MM-DD)
sort_by: str = "created_at"  # Поле сортировки
sort_order: str = "desc"     # Порядок (asc|desc)
```

**Валидация**:
- Pydantic модели с Field validators
- regex для sort_order: `^(asc|desc)$`
- Ограничения: page >= 1, 1 <= page_size <= 100

**Ответ**:
```json
{
  "items": [...],
  "total": 150,
  "page": 1,
  "page_size": 10,
  "total_pages": 15
}
```

### 4. Управление пользовательскими данными

#### CRUD операции с событиями:

| Метод | Endpoint | Описание |
|-------|----------|----------|
| POST | `/events` | Создание события |
| GET | `/events` | Список с фильтрацией |
| PUT | `/events/{event_id}` | Обновление |
| DELETE | `/events/{event_id}` | Удаление |

**Валидация на клиенте**:
- TypeScript интерфейсы
- Проверка обязательных полей

**Валидация на сервере**:
- Pydantic модели с field_validator
- Проверка формата даты (YYYY-MM-DD)
- Проверка формата времени (HH:MM)
- Ограничение длины title (1-200 символов)
- Минимальная длина пароля (6 символов)

**Обработка ошибок**:
- 404 - запись не найдена
- 403 - нет прав доступа
- 400 - некорректные данные
- 401 - не авторизован

**Бизнес-правила**:
- Пользователь видит только свои события (фильтр по user_id)
- Только авторизованные пользователи могут создавать/изменять данные
- Требуется верификация email для доступа

### 5. Объектное хранилище (S3-совместимое)

#### Конфигурация:
```python
S3_BUCKET = "lyfestyler-files"
S3_REGION = "us-east-1"
ALLOWED_CONTENT_TYPES = [
    "image/jpeg", "image/png", "image/gif",
    "application/pdf", "text/plain", "application/json"
]
MAX_FILE_SIZE = 10 * 1024 * 1024  # 10 MB
```

#### 5.1. Загрузка файлов
**Endpoint**: `POST /events/{event_id}/files`
- Проверка существования события
- Валидация типа и размера файла
- Генерация уникального ключа
- Сохранение в хранилище
- Создание записи в БД

#### 5.2. Получение файлов (pre-signed URL)
**Endpoint**: `GET /files/{file_key:path}`
- HMAC подпись URL
- Проверка срока действия
- Проверка прав доступа пользователя
- Отдача файла с правильным Content-Type

#### 5.3. Удаление файлов
**Endpoint**: `DELETE /events/{event_id}/files/{file_id}`
- Удаление из хранилища
- Удаление метаданных из БД
- Каскадное удаление при удалении события

#### 5.4. Ограничения
- Типы файлов: изображения, PDF, TXT, JSON
- Максимальный размер: 10 MB
- Проверка content-type при загрузке
